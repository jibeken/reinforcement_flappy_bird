# Flappy Bird Reinforcement Learning (Q-Learning)

Данный проект демонстрирует применение табличного алгоритма обучения с подкреплением **Q-learning** к классической игре Flappy Bird. Агент (птица) обучается перемещаться в фиксированной замкнутой среде, избегая столкновений с трубами и землей.

## Особенности реализации

* **Стабильное плато на графике:** Среда генерирует фиксированную последовательность из 15 труб (`PIPE_SEQUENCE`). При успешном прохождении последней трубы эпизод принудительно завершается. Это задает жесткий верхний потолок наград, заставляя график обучения выходить на горизонтальное плато (требование преподавателя).
* **Экспоненциальное сглаживание:** На графике параллельно отображаются «сырые» награды за каждый эпизод и скользящее среднее, что наглядно показывает прогресс сходимости алгоритма.
* **Экспорт результатов:** По окончании обучения скрипт автоматически сохраняет финальный график в формате `.png` и записывает демонстрационный файл `.gif` с игрой полностью обученного агента.

## Требования

Для запуска проекта необходим Python версии 3.8 или выше и библиотеки, указанные в `requirements.txt`.

Установка зависимостей:
```bash
pip install -r requirements.txt
```

##  Запуск проекта

Запустите главный скрипт для инициализации процесса обучения:
```bash
python train.py
```

*Во время обучения на экран будут выводиться два интерактивных окна: симуляция текущего игрового процесса птицы и обновляющийся в реальном времени график Accumulated Rewards.*

##  Математика наград и логика обучения

1. **Пространство состояний (State Space):** Непрерывные координаты игры квантуются в дискретные бакеты. Состояние описывается кортежем `(rel_y, dist, vel)`:
   * `rel_y`: относительное расстояние по вертикали от птицы до центра зазора трубы.
   * `dist`: горизонтальное расстояние до ближайшей трубы.
   * `vel`: текущая скорость птицы.
2. **Система поощрений (Reward Function):**
   * Успешный пролет через створ трубы: `+10`.
   * Столкновение с препятствием или падение на землю: `-20` (с немедленным завершением эпизода).
   * Обычный игровой шаг: `0`.

## Результаты работы

После завершения всех эпизодов в корневой папке проекта будут созданы файлы:
* `reward_plot.png` — итоговый график обучения со средней линией плато.
* `flappy_trained.gif` — анимация полета обученного агента (при `epsilon = 0`).
